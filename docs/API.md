# API 配置

## 一把 OpenRouter Key

1. 在 [OpenRouter](https://openrouter.ai/settings/keys) 创建 Key 并配置可用额度。
2. 游戏主页点击「AI 设置」，在顶部「统一 OpenRouter Key」中保存。
3. 在每位选手卡片中选择型号、思考档位、最长等待时间，勾选是否参赛。
4. 点「保存并验证看图 / 绘图」。这会发出两次计费请求，分别检查识图和有效笔画，结果中显示平台回执。

统一 Key 只发送给 `https://openrouter.ai/api/v1`。为某位选手另填 Key 会覆盖统一 Key；换到其他地址不会自动带上统一 Key。密钥保存于 `.local/credentials.json`，个人配置在 `.local/config.json`；这些路径已被 Git 忽略。环境变量 `OPENROUTER_API_KEY` 可替代网页保存的统一 Key。

## 各家官方 / 其他中转 / 本地模型

展开该选手的「名称、接入方式与角色形象」，选择接口协议，然后展开「接入与密钥设置」填写平台给出的完整 Base URL 与 Key。OpenAI 兼容服务使用 `/chat/completions`；Anthropic 原生协议使用 `/messages`；OpenAI / Grok 原生预设使用 `/responses`。不知道协议时，优先采用平台标注的 OpenAI 兼容方式。

型号 ID 必须来自该平台：OpenRouter 的 `厂商/型号` 通常不能直接用于官方接口。可展开「手动填写型号 ID」。千问平台附有资料快照；其他自定义服务不会冒充已有官方能力目录，需自行验证。支持本地 HTTP 回环接口；远程接口要求 HTTPS。

GPT 也走 API 默认值。仅在已安装并登录 Codex CLI 的电脑上，才需要手动改为「Codex 命令行」；无此工具时可忽略，不影响其他玩家。

## 速度、费用、能力

- 「自动快速档」对允许关闭思考的型号关闭思考，对强制思考型号使用目录支持的最低档。不同平台不一定支持全部档位。
- 不能通过思考强度把纯文本模型变成视觉模型。默认选择器只列出图片输入、文字输出的型号。
- 模型画图通过 JSON 笔画完成，原生生成图片的模型不适合此协议。
- 超时时间从发出请求开始计，最多可选 600 秒。多人同时请求可能触发平台限流；费用、延时和额度由平台决定。
- 型号目录联网失败时使用随仓库附带的快照，可手动输入新型号。游戏不会静默更换已保存的型号。
- 401/403 通常与 Key / 权限有关；404 检查地址和型号；429 检查余额、配额和速率；400 检查图片能力、协议与参数。

第三方服务的回执用于核对请求和响应，不构成模型真实性的独立认证。
