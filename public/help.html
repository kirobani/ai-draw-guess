本地版使用说明

开一局，再接上你的 AI。

所有 AI 默认通过 OpenRouter 接入。

运行 npm ci 安装依赖，npm start 启动后访问本页。游戏首页进入「AI 设置」，顶部保存统一 OpenRouter Key，再选择各位选手的型号并验证。无需安装 Codex。

高清角色：先运行 npm run setup:avatars，再按项目 docs/ASSETS.md 从 Live2D 官网获取并安装 Cubism Core。未安装完整资源时，API 设置和游戏规则仍可使用。

怎么开始

  1. 选「单人对战」或「多人混战」。点选选手；取消「你」即可纯 AI 观战。
  2. 选择成语、动物、食物、物品、职业、动作或故事，成语可选入门（常见易画）、进阶（常用扩展）或挑战（全量四字成语，含生僻词），再选择每人题数。
  3. 轮到你画：画布上方显示秘密答案。画好后点「画好了，开始猜」。
  4. 轮到 AI 画：画面生成后逐笔播放。猜手只收到画布图片，不能看到题目。
  5. 每次猜错，等所有选手完成这一轮后，让画手改画再猜。第三轮后公布答案。
  6. 比赛结束后查看总榜、最佳画手、最佳猜手及每一幅画的猜题记录，可导出 JSON 复盘。

提示方式三档

开局前在「提示方式」选择，默认第三档，浏览器会记住你的选择；开始后整场比赛使用同一规则，玩家与 AI 画手一致。

  1. 禁止提示：公开和单独提示都关闭，AI 返回的提示也会被丢弃，只能补画。
  2. 固定选项：恢复上一版，选择画面区域和观察重点后生成固定句子；不能自由写文字。区域须有相应笔画，比较类提示须有多笔。
  3. 画面文字：保持当前规则，可以自由提醒具体物体、动作和细节，或纠正误读。不要解释词义、寓意、典故或直接报答案；不做语义硬拦截。

三档第一轮都只看画；第二、三档从第 2 轮起允许公开或单独提示。单独提示仍只发给指定的未猜中者。传画接龙只传上一棒的画或词，不启用提示选项。当前规则会显示在题目栏及对局记录中。

清空、撤销与单独提示

点清空立即清除当前画布，不弹确认；点撤销或按 Ctrl+Z 可以一次恢复整幅画。清空后又画了新笔画，先撤销新笔画，再撤销清空。

使用第三档时，第 2、3 轮改画时，人类画手可以分别给每位未猜中的选手填写提示，也可以给所有人公开提示。AI 画手会参考各人的错误答案给出提示。提示可自由填写，指出画面中的具体物体、动作和细节，也可纠正选手看错的地方，比如“你当成树枝的长线是鱼竿”。请不要解释词语或成语的释义、寓意、典故，也别直接报答案。例如画了两匹马，可以提醒“看黑马身上的红圈”，不能说“想想马群里那匹惹祸的马”；图里没画出的品行、寓意和因果不能用提示补齐。公开和单独提示都会在同一次回复中自查，猜手也会被提醒忽略画外释义。这些要求通过提示词引导，不做关键词或画面区域的硬性拦截。单独提示只进入收件人的模型请求；你作为猜手只能看到给自己的提示。已猜中的人不再参与，也不能继续收提示。

展开聊天和作答

点「展开聊天 ↑」或「展开作答 ↑」可拉出大面板，顶部可切换聊天与作答。聊天保留筛选和历史；作答旁边可对照当前画布，输入中的答案和提示不会因展开、切换、收起而丢失。点「收起 ↓」或按 Esc 返回原来的位置。

计分和盲猜

第 1 / 2 / 3 次猜中分别获得 3 / 2 / 1 分。画手同时获得所有猜中者对应的分数。人类与 AI 使用完全相同的规则：画手不猜自己的题，每题均由其他 N−1 位选手猜。多人比赛每次开局都会把参赛顺序重新打乱，玩家也参与抽签；同一局中按这个顺序轮流作画，不会每题重新抽签。完整赛程中每人的作画和猜题满分机会相同。

猜手只收到：当前画布 PNG、类别、字数、公开提示、只给自己的单独提示，以及自己此前猜错的答案。提交后按模型自己的把握显示自信、犹豫或瞎蒙；所有选手交卷后短暂停留，再统一判断对错和计分。具体答案在本题结束后显示。画手可以看到错误答案来改画。

答案按标点、空格规范化后匹配，另有少量预设别名，例如「冰激凌 / 冰淇淋」「单车 / 自行车」「风烛残年 / 风中残烛」。四字成语额外放宽：提交四个汉字，四字及重复次数与答案一致但顺序不同，或至少三个字在原位置正确，也算猜中，照常得分。例如「画龙点睛」可接受「点睛画龙」和「画龙点精」。少字、多字或列出多个候选不享受此规则；其他分类仍按原规则判定。最佳画手与猜手按各自得分占可得满分的比例评选，并列时同时展示。

传画接龙怎么玩

大厅选择「传画接龙」。N 位选手各拿到一个不同题目，同时开始画图；全员交卷后，将画传给各自队列的下一人猜词，再把猜出的词传给下一人画图。全场按棒次同步，画图与猜词交替进行，共 N 棒。

每次开局随机生成均衡队列：每条链里每位选手恰好出现一次；同一棒每人只接一条链；全部链走完后，每个人恰好做过一次第 1 到第 N 棒。每人只能看到上一棒的图或词，不能看原题和之前的历史。猜手会知道本局题库分类；成语局每次都要求猜一个四字成语。奇数人数以画图收尾，偶数人数以猜词收尾。

接龙不按猜对与否计分，也不纠正歪掉的词。全员完成后进入揭晓时间。点「开始展示」，每幅画停留 4 秒，配音效后公布下一位猜的词，猜词停留 3 秒再到下一棒；可暂停或手动下一棒，刷新后继续。每条链播完展示原词 → 末棒词语或画面。末棒为猜词且文字与原词完全一致时，直接通过，免投票；AI 各发表一句通关感言，玩家可选留言，感言保存在聊天和复盘里。每位 AI 的感言替代这条链原本的投票调用，可重试失败感言或跳过未完成的感言。末棒为画面或词语不完全相同时，全员投票过不过。通过票多于不通过票才算过，平票不过，弃权不计入有效票；没有有效票则标记无法判定。没通过再投「最大害群之马」，每人选一位造成最大偏离的选手，可以投自己，并列最高票一起公布。AI 依据全链作品独立投票，不会看到其他人的票；理由按角色性格直接点名，以朋友互怼的语气指出具体问题，编号只用于对应画作；每链每位 AI 增加一次通过票调用，失败链再增加一次选人调用。投票失败可重试，或明确记为弃权，不会冒充投票。全部展示结束后可回看每棒大图、全部票数与理由，也可导出完整接龙。提前结束仍保留旧的直接展开方式。连接失败可以只重试失败选手，已交卷内容保留；主动留空或跳过失败棒次会让该链后续留空，复盘明确记录原因。刷新网页可恢复已交卷内容，未提交的本地画稿不会保存。

每位 AI 每棒调用一次，因此一局约为 AI 人数 × 总人数次模型调用；收费方式沿用各自的型号配置。模型回复速度不同，等待最慢一位交卷后统一传递。

角色气泡和对局聊天

提示、猜词和简短理由从对应角色的气泡出现，旧消息会保留在画布下方的「对局聊天」。可筛选提示、猜词与理由、赛后复盘；往上翻看时不强制跳回底部，点击「有新消息」或勾选「跟随最新」回到最新内容。刷新网页可以恢复本场记录，结束比赛后仍可查看并随复盘一起导出。

你作画时可以看各位猜手的答案和理由；你猜题时，其他人的答案在整题结束后公开。观战可看已统一判分的猜词。单独提示在本题结束前只对画手和收件人显示。

整题无人猜中时，角色根据已提交猜词、简短理由和最终画面补充一句话复盘。「心路历程」只回顾实际提交的记录。每位 AI 会额外调用一次模型；切换下一题不必等它完成，未完成或调用失败的部分保留为记录摘要，分数不受影响。

怎么选模型

  1. 点游戏右上角「AI 设置」，找到对应选手，在「选择型号」下拉框中挑选。GPT 读取本机 Codex 可见型号；OpenRouter 读取平台目录，并按角色所属厂商筛选。千问 AI 平台使用按官方资料核对的型号列表，可直接下拉选择；默认显示有视觉能力的型号。
  2. 默认仅显示目录标注支持图片输入和文字输出的型号。「目录支持识图」不等于已在本机通过测试。
  3. 点「保存并验证看图 / 绘图」。它会让模型看图猜一把雨伞，再生成自行车的游戏笔画，两次调用按所用服务计费。
  4. 展开「查看实测结果与型号回执」，可查看请求型号、平台返回型号、承载服务、请求编号与实际生成的自行车。换型号后旧测试记录不再沿用。

识图用于猜题；游戏绘图是输出线条、椭圆等简笔画指令，不需要原生图片生成模型。通过测试表示该次请求可完成这些任务，不保证每次猜对或画得好。

一把 OpenRouter Key 共用同一账户余额；每个选手在请求里单独指定完整型号 ID。游戏不设置备用型号，也不请求随机路由。平台返回的型号是核对凭据，不能独立证明平台内部使用的权重。GPT 目前走本机 Codex 登录，不消耗 OpenRouter 余额；命令行没有提供服务端型号回执，会如实标注。

模型价格来自目录，显示每百万文字 token 的输入 / 输出美元价格，图片等费用按平台计费。型号目录不是账户权限清单，实际可用性以验证结果为准。修改设置影响下一场比赛，当前对局仍使用开局配置。

平台、思考强度与等待

每位选手卡片现在都有「接入平台」「选择型号」「思考强度」「最长等待」四项。平台切换会使用本机已保存的对应平台密钥，不需要重复粘贴。千问平台可接千问、DeepSeek、Kimi 和 GLM；GLM 的智谱直供型号需在千问模型市场开通。尚未开通时可以选择 OpenRouter。GPT 仍可使用本机 Codex。

「自动快速档」优先关闭可选思考；不能关闭的型号使用其支持的最低档。「平台默认」不指定强度，部分型号的默认值很高。其他选项按所选型号的真实能力展示，不会给不能关闭思考的型号发送关闭参数。没有可核实的参数目录时仅保留自动／平台默认，手动型号不假装支持所有档位。强度越高通常越慢，也可能增加消耗；复杂画面不保证快速档也能猜对。

每位选手可选择 60、120、150、180、300 或 600 秒的最长处理时间。计时从请求发出后开始；超时后允许重试或跳过。本机普通比赛和接龙均最多同时处理 12 路模型请求，一桌猜手同时发出；额外会话超过上限才排队。平台自身的限流和处理速度仍以实际服务为准。

基础测试使用雨伞和自行车，只检验本次接口与格式，不能代替复杂成语比赛的性能验收。更换平台、型号、强度或等待上限会让旧实测标记失效。

各选手可以分别使用 OpenRouter 或官方 API。只改型号不需要重新填密钥。需要更换服务时展开「接入与密钥设置」，填写基础地址和 API Key；地址不追加 /chat/completions、/responses 或 /messages。也可以继续使用以下厂商直连方式，手动填写其型号 ID。

千问的速度与型号

千问 3.8 的平台默认思考力度较高。游戏的「自动快速档」会关闭可选思考，也可在「思考强度」选择低、中、极高。修改影响下一场比赛。每次验证分别显示看图和绘图耗时，合计为两次请求的总耗时。

官方兼容接口没有 GET /models，游戏内置按官方资料核对于 2026-10-09 的型号列表，不把它当作账户权限清单。部分 Max 或开源型号仅支持文字，勾选「也显示仅文字型号」可以查看；游戏中需要看图猜题时，请选视觉型号并验证。价格以各型号官方页面为准。

Codex 登录

这是可选接入方式，默认 GPT 使用 OpenRouter。若需本机登录，可按官方文档安装 Codex，执行 codex login 完成登录，再重启游戏。模型调用会使用该登录对应的可用额度。游戏不会读取或复制登录令牌。

密钥放在哪里

统一 OpenRouter Key 保存在 .local/credentials.json；每位选手单独填写的密钥会保存到游戏目录的 .local/config.json，属于本机明文配置。网页读取配置时只得到「是否已配置」，不会得到密钥。不要把这个隐藏目录发给别人。新增提供商也可使用 DEEPSEEK_API_KEY、XAI_API_KEY、MOONSHOT_API_KEY、DASHSCOPE_API_KEY、ARK_API_KEY。也可以在启动前设置 OPENAI_API_KEY、ANTHROPIC_API_KEY、GEMINI_API_KEY、ZHIPU_API_KEY 环境变量。官方 API 按各平台账户计费；看图 / 绘图验证会发起两次真实请求。

画画需要生图 API 吗？

不需要。文字模型输出受限的线条、椭圆、多边形等画笔指令，游戏把它们画到画布上，再将画布图片发给视觉模型猜。模型输出不会被当作脚本执行。改画时优先保留上一幅画，撤回末尾必要的笔画，再补上新笔画。播放会逐笔显示撤回和落笔，一笔内部也会渐渐画出。画布旁可选择播放速度或直接看完整画面。

失败时怎么处理

  • 没有可用 AI：打开「AI 设置」填写密钥，或确认 Codex 已安装并登录。
  • 401 / 403：检查密钥及模型权限。404：检查模型 ID 和接口基础地址。
  • 400：确认选的是支持图片输入的模型，并检查兼容接口是否接受标准图片消息。
  • 模型超时：可降低思考强度、调整最长等待后开始新比赛，或在当前局重试／跳过。默认 Codex 180 秒、API 150 秒，可各自调到 60–600 秒。
  • 猜题连接失败：机会不会自动扣除；可重试，或主动跳过这次机会。
  • 画手掉线：重试画图或跳过本题。答案不会因连接失败提前发给其他 AI。
  • 页面关了：重新打开同一浏览器里的本地地址即可继续。关闭服务、电脑重启或清除浏览器 Cookie 后，内存里的比赛不会恢复；结束后请导出复盘。

复刻范围

本版依照所提供视频的玩法和布局重新实现，包含单人、多 AI 混战、7 类题库、逐笔画图、人类绘画工具、独立盲猜、改画提示、三次机会、双向计分和赛后画廊。成语分入门 218 题、进阶 2,000 题和挑战 29,508 题，动物、食物、物品、职业、动作、故事也各分入门、进阶、挑战三档，每类入门至少 200 题，高档包含低档词库。故事类包含经典故事与原创生活小情节；没有原作源码或私有接口。本地运行，不提供多人联网房间。

可动角色

十一位角色都可以在角色排练室预览，并切换表情和绘画动作。

打开角色排练室：DeepSeek、Gemini、Claude、ChatGPT、Grok、GLM、Kimi、千问、豆包、MiMo、MiniMax。每位使用 Kit 高清九表情版：待机、画画、画完等待、自信、犹豫、瞎蒙、庆祝、吃瓜、猜错。猜词时在同一次回复里附上主观把握值：75–100 显示自信，40–74 显示犹豫，0–39 显示瞎蒙。这个数值不代表实际正确率，也不参与判分；未返回有效数值时，随机固定一种等待表情。猜中先庆祝约 4.5 秒，再吃瓜围观。接龙提交猜词也会按把握显示表情，不提前公开猜词。无需额外模型请求，只增加少量提示和一个回复字段。大厅会提前加载已选参赛者的角色，并显示准备进度；等到“参赛角色已就绪”后，进场直接复用这些角色。提前开局也会继续原来的加载，不会重新开始。取消选手会释放对应角色，再来一局会保留已准备好的角色；加载失败可单独重试。首次加载仍需时间，刷新整个网页也需重新初始化。对局中所有 AI（包括当前画手）各有一个独立 Live2D 席位，显示选手名、实际配置的完整模型型号、分数和当前状态；玩家保留简洁文字席位。暂停动作会同时暂停所有席位，恢复后继续显示各自状态。

角色拥有独立绘制的表情和拿画板姿势，使用原生 Cubism 模型。当前为自动绑定的动作样板，头部、身体与头发有动作，握笔手尚未单独绑定逐指动作；没有音频口型或摄像头面捕。动画在本机运行，无需 API Key。形象与 AI 接口分别选择，出现角色不代表已连接该厂商。
